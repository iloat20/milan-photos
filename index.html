Upload

添加你的照片

先在本机预览；配置 GitHub 后会一并写入仓库，Pages 站点同步更新。

同步到 GitHub

在 GitHub → Settings → Developer settings → Personal access tokens 创建， 勾选 repo（classic）或本仓库 Contents: Read and write（fine-grained）。 Token 只存在这台设备的浏览器里。

把图片放进 photos/，运行 python tools/sync_photos.py（或推送后由 Actions 自动生成清单）即可上墙。
